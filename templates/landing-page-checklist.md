# Checklist de Conteúdo — Revisão de Landing Page

Use este checklist para verificar se a landing page recriada contém todo o conteúdo da original.

## Estrutura

- [ ] **Navegação / Logo** — Nome da marca ou logo presente no topo
- [ ] **Hero Section** — Headline principal, subtítulo e CTA primário
- [ ] **Prova Social** — Números, estatísticas, logos de mídia, badges de confiança
- [ ] **Benefícios / Features** — Seção explicando os benefícios do produto/serviço
- [ ] **Conteúdo do Produto** — Módulos, etapas, funcionalidades detalhadas
- [ ] **Depoimentos** — Testemunhos com nomes e contexto (roles, localização)
- [ ] **Preços** — Tabela de preços, opções de pagamento, valor original vs promocional
- [ ] **Garantia** — Política de garantia/devolução claramente apresentada
- [ ] **Sobre o Autor/Instrutor** — Bio, credenciais, foto placeholder
- [ ] **FAQ** — Perguntas frequentes com todas as perguntas da original
- [ ] **CTA Final** — Chamada para ação de fechamento com botão
- [ ] **Footer** — Dados da empresa, CNPJ, contato, redes sociais

## Conteúdo Textual

- [ ] **Headlines** — Todos os títulos principais estão presentes
- [ ] **Parágrafos** — Textos explicativos mantêm a essência da mensagem
- [ ] **CTAs** — Todos os textos de botões de ação estão presentes
- [ ] **Preços exatos** — Valores monetários estão corretos
- [ ] **Dados de contato** — Email, telefone, redes sociais
- [ ] **Dados legais** — CNPJ, razão social, endereço

## Critérios de Aprovação

- **PASS**: Todos os itens marcados ou item não existe na página original
- **FAIL CRÍTICO**: Falta headline, CTA, preço ou seção inteira
- **FAIL MENOR**: Falta texto secundário, dado de contato ou detalhe do footer
